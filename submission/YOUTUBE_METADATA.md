## Description

OpsCrew is a guarded expense-operations copilot created from scratch in Google AI Studio Build for AI Builder Cup 2026. This revision follows the owner's actual submission field requiring a 3–4 minute demonstration.

Live prototype: https://opscrew-883881551915.us-central1.run.app
Public source: https://github.com/sundaylee3100-ljl/AI-Builder-Cup-2026-OpsCrew

Gemini extracts facts, proposes a handling plan and separately reviews it. Fixed checks validate synthetic policy citations, facts, permitted actions and the current input version. The demonstration follows a synthetic USD38 missing-receipt example. A person prepares the eligible case, checks the confirmation box and explicitly confirms creation. The application then retrieves the saved case independently through its server API and shows the same visitor's history. It does not execute payments or send employee messages.

The prototype uses Google Cloud Run, Firebase Authentication and Cloud Firestore. This video demonstrates one recorded example; it makes no universal accuracy, latency, spending-cap, immutable-ledger or cryptographic-verification claim.
